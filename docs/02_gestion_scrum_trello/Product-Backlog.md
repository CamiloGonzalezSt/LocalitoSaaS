# Product Backlog — Localito

El Product Backlog se mantiene priorizado según valor, dependencias y riesgo.

| Épica | Historias/capacidades principales | Prioridad |
|---|---|---|
| Plataforma SaaS | autenticación, roles, locales, suscripción, permisos | Alta |
| POS | ticket, venta, pagos, venta en espera, idempotencia | Alta |
| Inventario | productos, stock, kardex, alertas, CSV | Alta |
| Clientes y fiado | clientes, cupo, deuda, abonos, vencimientos | Alta |
| Caja | apertura, movimientos, cierre, diferencias | Alta |
| Compras | proveedores, órdenes, recepción, costo promedio | Media |
| Reportes | métricas, filtros, comparación, exportación | Media |
| Auditoría | acciones, autor, antes/después, filtros | Media |
| PWA/offline | instalación, caché, cola de ventas | Media |
| IA visual | Venta Rápida e ingreso de factura | Media |
| UX/UI | responsive, accesibilidad, tema claro/oscuro | Media |
| Calidad/operación | pruebas, despliegue, seguridad, documentación | Alta |

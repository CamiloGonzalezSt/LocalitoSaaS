# Metodología declarada y justificada — Scrum

Localito utiliza **Scrum** como metodología ágil de gestión.

## Justificación
Se eligió Scrum porque el proyecto requiere construir un producto funcional por incrementos, validar continuamente el resultado y ajustar prioridades a medida que aparecen necesidades técnicas o de negocio. El alcance contiene módulos independientes pero relacionados —POS, inventario, caja, clientes, compras, reportes e IA— que pueden desarrollarse y revisarse iterativamente.

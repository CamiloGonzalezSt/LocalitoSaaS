# SRS — No aplica como artefacto principal

El criterio de evaluación indica que la SRS formal aplica a equipos que declaran metodología **Cascada**.

Localito declara y justifica **Scrum** como metodología vigente, por lo que la SRS no es el artefacto principal esperado. Los requisitos funcionales y no funcionales se documentan dentro de la estructura Scrum y de requisitos del proyecto.

# Innovación y valor agregado — Localito

## Problema que resuelve
Pequeños comercios suelen administrar ventas, stock, fiado, caja y compras de manera fragmentada, lo que aumenta errores y dificulta tomar decisiones.

## Qué hace diferente
Localito integra en una PWA SaaS flujos que normalmente se encuentran separados y añade IA visual dentro de tareas concretas del negocio.

## Innovaciones del MVP
- Venta Rápida: foto de varios productos para proponer coincidencias y cantidades del catálogo.
- Ingreso desde factura: extracción asistida de productos, cantidades y costos con revisión humana.
- PWA instalable sin exigir una aplicación nativa.
- Cola local acotada para ventas cuando existe inestabilidad de red.
- Modelo multi-negocio con roles, trazabilidad y auditoría.

## Principio de seguridad funcional
La IA no descuenta stock ni crea operaciones por sí sola. Propone información y el usuario confirma antes de afectar datos.

## Valor agregado
- Reduce pasos manuales.
- Centraliza información operativa.
- Mejora trazabilidad.
- Facilita adopción móvil.
- Mantiene un enfoque accesible para comercios pequeños.
